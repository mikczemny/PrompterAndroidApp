# Changelog

All notable changes are documented here. The project follows semantic version
names and monotonically increasing Android version codes.

## [Unreleased]

- Further GUI refinement before production publication.

## [1.3.0] - 2026-08-12

- Added SelfiePrompter and ExtPrompter setup modes.
- Added draggable, pinch-resizable CameraX selfie preview with adaptive text.
- Added paired silent MP4 and high-quality WAV recording with Save/Discard.
- Added recordings library, selectable SAF destination and video opening.
- Added highlighted last recognized word, audio-focus handling and Back flow.
- Moved all user-facing UI/import messages to string resources.
- Added open-source licenses screen, release AAB configuration and CI.
- Added publication-readiness documentation and current Play checklist.
- Added foreground-only recording and camera/microphone disclosures.
- Added safe active-take navigation and stale temporary-take cleanup.
- Pinned SHA-256 for all 11 downloadable Vosk model archives.

## [1.2.0] - 2026-07-23

- Added on-device script recordings and import/editor hardening.
- Added localization-ready string resources, audio focus and licenses screen.
- Added CI and release App Bundle/signing configuration.

## [1.1.0] - 2026-07-22

- Added script library and PDF, DOCX, TXT and Markdown import.
- Added formatting tools, tap-to-jump, reset and stage controls.

## [1.0.0] - 2026-07-22

- Initial native Android voice-following teleprompter with 11 Vosk languages.
